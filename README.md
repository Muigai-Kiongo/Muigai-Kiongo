### Executive Profile

Software Engineer and Founder based in Nairobi, Kenya, specializing in end-to-end system architecture, payment gateway integrations, and containerized cloud deployments. Through **MKON Networks**, I design and operate scalable software solutions that bridge modern web interfaces with fault-tolerant backend infrastructure.

- **Platform Engineering:** Architecting multi-tenant SaaS/PaaS ecosystems, self-service developer consoles, and automated deployment pipelines.
- **Backend & FinTech Systems:** Building high-concurrency APIs, real-time WebSocket services, and automated **M-Pesa Daraja (C2B, B2C, STK Push)** payment workflows.
- **Frontend & Mobile Delivery:** Engineering responsive, data-driven web applications in React/Next.js and native Android clients in Kotlin/Jetpack Compose.
- **Cloud & DevOps Operations:** Managing production Linux VPS clusters orchestrated with Docker, Docker Compose, Traefik reverse proxies, and automated SSL.
