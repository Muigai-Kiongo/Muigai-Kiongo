I am a software engineer based in Nairobi, Kenya, focused on architecting reliable full-stack systems—from backend APIs and payment integrations to responsive web frontends and native Android apps.

- **Building:** Multi-tenant SaaS/PaaS ecosystems, developer infrastructure, and bespoke digital solutions at **MKON Networks**.
- **Specializing in:** Python/Django backends, React/Next.js frontends, Kotlin/Jetpack Compose mobile apps, and **M-Pesa Daraja API** integrations.
- **Infrastructure & Ops:** Deploying and managing containerized production workloads using Docker, Traefik, and Linux VPS nodes.
- **Open to:** Collaborating on full-stack web applications, DevOps automation, and open-source tooling.
